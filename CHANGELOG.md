# Changelog

## v1.3.0

### Added
- About 70 new apps and six new sections: browsers, media, messengers, local AI, development, reverse engineering. New groups in utilities and system administration, including emulators, documents and a group for bypassing blocks.
- Keyboard shortcuts: `/` focuses the search, `Esc` clears it.
- The set bar prints the winget command for the picked apps as you pick them.

### Changed
- New interface: a section rail, list rows instead of cards, a phone layout and a refreshed dark theme. It uses system fonts only, so nothing is loaded from third-party servers.
- The catalog is published on GitHub Pages and the app reads it from there.
- Fixed catalog entries whose repositories had moved. A few archived apps stay listed and are marked.

### Moved
- The project now lives in one public repository, `barnibeats/windows-toolbox`. The old `windows-toolbox-releases` repository is retired. Copies of v1.0 to v1.2.1 that are already installed get this release through the old update address one last time.
